# 昆虫辨识 PWA — 设计文件 / Insect ID PWA — Design

日期：2026-10-21
状态：待确认（Draft, awaiting approval）

## 1. 目的与原因

用户在马来西亚野外拍到昆虫时，用 Google 搜图得到的结果太杂，无法判断哪个是对的。
这个 App 先帮用户把一只陌生的昆虫可靠地归到"目"（例如鞘翅目、半翅目），并给出
可以对照验证的特征，而不是给一堆相似图片。

内容基础是《游黽飛蛉：台江昆蟲圖鑑》（台江國家公園管理處，2015）中通用的入门章节：
认识昆虫、细看昆虫（形态）、昆虫的多样性、生活史、常见昆虫快速辨识。
物种层级内容不在第一版。

这个版本同时作为向 UMS《Insects of Malaysia: A Field Guide》编者展示的原型；
日后若取得授权，物种内容可以接上同一套结构。

## 2. 目标

1. **一步一题的辨识流程**：根据台江图鉴第 38–40 页的二分检索表，每一步只问一个
   看得见的特征（有没有翅、几对翅、前翅是否硬化成翅鞘、前足是否为捕捉足……），
   3–6 步内落到一个类群，再连到该目的介绍页。
2. **目的介绍页**：每个目一页，含辨识特征、变态类型、常见代表、容易混淆的类群。
3. **认识昆虫**：可点击的昆虫身体示意图（头、胸、腹，触角、复眼、单眼、口器、足、翅、
   小楯片、尾毛等），点一下显示中英名词解释；同时说明"哪些不是昆虫"。
4. **生活史**：无变态、不完全变态、完全变态三种，各附示意图与代表目。
5. **中英双语**：简体中文与 English，可随时切换，记住用户的选择。
6. **完全离线**：第一次打开后，所有页面与图片都能在没有讯号的地方使用；可加到手机主画面。

## 3. 非目标（第一版不做）

- 物种层级辨识（台江图鉴的 180 种物种页）。
- AI 照片辨识。
- 用户账号、云端同步、观察记录上传。
- 马来文（结构上预留，内容日后再加）。
- 害虫防治建议。

## 4. 反目标（做出来但若出现这些就算失败）

- 辨识流程给出错误或过时的分类（例如把白蚁列为独立的等翅目而不说明、把弹尾虫当昆虫）。
- 在野外看不清楚：字太小、按钮太小、阳光下对比不足。
- 需要网络才能用。
- 使用台江图鉴或其他来源中有版权的照片或原文段落。
- 让用户以为结果是确定的鉴定；必须保留图鉴原有的提醒：检索表只适用于常见昆虫，
  存在例外，精确鉴定仍需请教专家。

## 5. 约束

- **版权**：不复制台江图鉴的照片、插图或原文段落。事实性内容（特征、分类、检索逻辑）
  用自己的文字重写，并在"关于"页注明参考来源。所有图像为自绘 SVG 示意图。
- **分类正确性**：以现行分类为准，修正来源中的过时用法：
  - 白蚁：列于蜚蠊目（Blattodea）之下，注明"旧称等翅目 Isoptera"。
  - 衣鱼目：Zygentoma（旧称 Thysanura）。
  - 同翅目已并入半翅目。
  - 弹尾虫、原尾虫、双尾虫：六足动物，但不属昆虫纲，放在"哪些不是昆虫"。
- **部署**：纯静态文件，可放在任何静态主机（GitHub Pages 或 woobrothers.my 的子路径）。
  所有路径使用相对路径，不能假设在网站根目录。
- **大小**：全部预缓存资源控制在 2 MB 以内，方便在流量有限时安装。

## 6. 已决定的做法

（以下为我的决定，未经用户逐项确认，可以否决。）

- **技术**：原生 HTML + CSS + JavaScript（ES modules），不用框架、不需要建置步骤。
  理由：内容量小、需长期维护、离线缓存简单。
- **资料与界面分离**：检索树、各目资料、名词表、生活史都放在 JSON 文件中，
  每个文字栏位都有 `zh` 与 `en` 两个值。日后加马来文或物种只要加资料。
- **离线**：Service Worker 采用"预缓存全部资源、缓存优先"；版本号变更时更新缓存，
  并在页面上提示"有新版本，点此更新"。
- **语言**：预设跟随手机语言（中文系统显示中文，其他显示英文），可手动切换，
  选择存于 localStorage。
- **外观**：大字（内文至少 17px）、大按钮（至少 48×48px）、高对比；支援深色模式。
- **辨识流程的互动**：
  - 每题显示示意图与两个（少数三个）大按钮。
  - 顶部显示已回答的路径，可点任一步返回修改。
  - 每题都有"看不清楚"选项：显示这一题的提示（例如怎么看翅的质地），而不是猜。
  - 结果页显示：类群名、所属目、关键特征核对清单（用户逐项打勾确认）、
    容易混淆的类群与区分方法、"前往该目介绍"。
- **检索表范围**：照台江图鉴，覆盖 12 个目、约 22 个常见类群（成虫）；
  另加"幼虫/若虫"提示：检索表只适用于成虫。

## 8. 页面结构

1. 首页：大按钮"开始辨识"，次要入口"认识昆虫""生活史""各目一览"。
2. 辨识流程（一题一画面）→ 结果页。
3. 认识昆虫（身体图 + 哪些不是昆虫 + 口器 + 足）。
4. 生活史。
5. 各目一览 → 各目介绍页。
6. 关于。

底部导航固定四项：辨识、认识昆虫、各目、更多。

## 9. 品质检查

- 自动检查资料：检索树的每个结果都指向存在的目页面、没有走不到的节点、
  没有循环；每个文字栏位中英都有内容。
- 浏览器测试：走完至少三条完整辨识路径；切换语言；离线状态下重新载入仍可使用。
- 内容核对：分类修正逐项对照第 5 节。

## 附录 A：台江图鉴快速辨识检索表（第 38–40 页）逐条整理

以下为原图的判断逻辑（成虫适用），作为辨识流程的基础。括号内为原书页码。
实作时按第 5 节修正分类名称。

```
起点
├─ 无翅
│  ├─ 水栖 → 海黽（半翅目）(p.102)
│  └─ 陆栖
│     ├─ 触角念珠状 → 白蚁（工蚁或脱翅生殖蚁）(p.86)
│     └─ 触角膝状 → 蚂蚁（工蚁或脱翅生殖蚁）(p.222)
└─ 有翅
   ├─ 一对翅（双翅目）
   │  ├─ 触角短（短角亚目）→ 蝇、虻 (p.175)
   │  └─ 触角长（长角亚目）→ 蚊、蠓、蚋（书中未收录）
   └─ 两对翅
      ├─ 翅有鳞粉 → 蝶、蛾（鳞翅目）(p.180)
      └─ 翅无鳞粉
         ├─ 刺吸式口器（半翅目）
         │  ├─ 前翅分革质、膜质 → 椿象、水黽（异翅亚目）(p.92)
         │  └─ 翅全为膜质 → 蝉、蚜虫 (p.90)
         └─ 其他类型口器
            ├─ 前后翅同质地
            │  ├─ 停栖时前后翅平贴腹部
            │  │  ├─ 没有明显的腰
            │  │  │  ├─ 触角念珠状 → 白蚁（有翅生殖蚁）(p.86)
            │  │  │  └─ 触角非念珠状 → 草蛉、蚁蛉、长角蛉、螳蛉（脉翅目）(p.225)
            │  │  └─ 具有明显的腰
            │  │     ├─ 腰上有两个突起 → 蚂蚁（生殖阶级）(p.222)
            │  │     └─ 腰上无突起 → 蜂类 (p.212)
            │  └─ 停栖时前后翅竖立或往两侧摊平
            │     ├─ 触角短
            │     │  ├─ 前后翅约等大 → 豆娘（均翅亚目）(p.45)
            │     │  └─ 后翅较大 → 蜻蜓（差翅亚目）(p.48)
            │     └─ 触角长 → 蚁蛉、长角蛉 (p.225)
            └─ 前后翅不同质地
               ├─ 具尾铗 → 蠼螋（革翅目）(p.233)
               └─ 不具尾铗
                  ├─ 前翅特化成翅鞘 → 甲虫（鞘翅目）(p.122)
                  └─ 前翅非翅鞘
                     ├─ 前足为捕捉足 → 螳螂 (p.79)
                     └─ 前足非捕捉足
                        ├─ 后足明显较发达
                        │  ├─ 触角长 → 螽斯、蟋蟀（剑尾亚目）(p.73)
                        │  └─ 触角短 → 蝗虫、蚤蝗（锥尾亚目）(p.63)
                        └─ 后足无明显不同
                           ├─ 前足为挖掘足 → 蝼蛄 (p.75)
                           └─ 前足非挖掘足 → 蜚蠊 (p.83)
```

精确鉴定仍须请教专家。
