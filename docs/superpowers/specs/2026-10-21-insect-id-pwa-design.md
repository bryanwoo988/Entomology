# 昆虫 · Bugs · Serangga — 设计文件

日期：2026-10-21（修订 2）
状态：待确认（Draft, awaiting approval）

## 1. 目的与原因

用户在马来西亚野外拍到昆虫时，用 Google 搜图得到的结果太杂，无法判断哪个对。
这个 App 做三件事：

1. 把一只陌生的昆虫可靠地归到"目"，并给出可以对照验证的特征；
2. 认识马来西亚农业上常见的昆虫（害虫与益虫），每一种都连回它所属的目；
3. 帮用户把这些知识记住：从名字由来、对比表、口诀，到闪卡、测验与考试。

基础入门内容参考《游黽飛蛉：台江昆蟲圖鑑》（台江國家公園管理處，2015）的通用章节；
马来西亚的目与常见代表参考 WTKhoo《Orders of insects in Malaysia》；
农业昆虫资料来自 MPOB、MARDI、DOA 与同行评审期刊。

## 4. 内容

### 第 1 阶段：认识昆虫（参考台江图鉴 p.20–33，重写）
1. 什么是昆虫：六足、头胸腹三体区、多数有翅。
2. 哪些不是昆虫：蜘蛛、蜱、蝎子、蜈蚣、马陆、虾蟹；弹尾虫、原尾虫、双尾虫（六足动物但非昆虫纲）。
3. 头部：触角 7 型（丝状、念珠状、膝状、棍棒状、锯齿状、羽状、鳃叶状）、复眼、单眼、
   口器 5 型（咀嚼式、刺吸式、虹吸式、舐吸式、嚼吸式）。
4. 胸部：足的六节、特化足（捕捉、挖掘、游泳、跳跃、步行）。
5. 翅：鞘翅、半鞘翅、覆翅、鳞翅、膜翅、平衡棒；翅各部位；小盾片。
6. 腹部：产卵器、尾须、螫针、尾铗。
7. 可点击的昆虫身体图：点部位显示三语解释，并连到名词表。

### 第 2 阶段：分类与快速辨识
1. 分类阶层与学名的读法。
2. 一步一题的辨识流程（见第 5 节）。
3. 剪影辨识练习。

### 第 3 阶段：生活史（参考台江图鉴 p.34–35）
1. 蜕皮。
2. 无变态、不完全变态、完全变态，各附示意图与代表目（已修正分类）。
3. 幼虫类型（蠋型/毛虫、蛴螬型、蛆型、蠕虫型）与蛹的类型。
4. 为什么农民要懂生活史：很多害虫是幼虫阶段造成危害；防治时机看虫期
   （以 MPOB 袋蛾生活史照片为例）。

### 第 4 阶段：各目介绍

主要 16 目，每目一页：

| 目 | 马来西亚常见代表 |
|---|---|
| 鞘翅目 Coleoptera | 瓢虫、犀角金龟、萤火虫、象甲 |
| 鳞翅目 Lepidoptera | 蝴蝶、蛾、弄蝶 |
| 半翅目 Hemiptera | 蝽、蝉、飞虱、蚜虫、粉虱 |
| 膜翅目 Hymenoptera | 蜜蜂、无刺蜂 kelulut、胡蜂、蚂蚁 |
| 双翅目 Diptera | 家蝇、实蝇、蚊、食蚜蝇 |
| 直翅目 Orthoptera | 蝗虫、螽斯、蟋蟀、蝼蛄 |
| 蜻蜓目 Odonata | 蜻蜓、豆娘 |
| 螳螂目 Mantodea | 螳螂、兰花螳螂 |
| 蜚蠊目 Blattodea | 蟑螂、白蚁（注明旧称等翅目） |
| 竹节虫目 Phasmida | 竹节虫、叶䗛 |
| 缨翅目 Thysanoptera | 蓟马 |
| 革翅目 Dermaptera | 蠼螋 |
| 脉翅目 Neuroptera | 草蛉、蚁蛉 |
| 蜉蝣目 Ephemeroptera | 蜉蝣 |
| 毛翅目 Trichoptera | 石蛾 |
| 衣鱼目 Zygentoma | 衣鱼（注明旧称 Thysanura） |

另有简短条目：襀翅目、广翅目（鱼蛉）、长翅目、蚤目、虱目（Psocodea）、纺足目、缺翅目。

每个目的页面：名字由来、3–5 项关键特征、变态类型、口器类型、马来西亚常见代表、
农业相关物种（连到第 5 阶段）、容易混淆的类群与区分方法、口诀、小测验。

| 水稻 | 褐飞虱 *Nilaparvata lugens*、绿叶蝉 *Nephotettix virescens*、稻缘蝽 *Leptocorisa oratoria*、三化螟 *Scirpophaga incertulas*、稻纵卷叶螟 *Cnaphalocrocis medinalis* | — |
| 蔬菜 | 小菜蛾 *Plutella xylostella*、斜纹夜蛾 *Spodoptera litura*、草地贪夜蛾 *S. frugiperda*、烟粉虱 *Bemisia tabaci*、蓟马 *Thrips palmi*、棉蚜 *Aphis gossypii*、瓜实蝇 *Zeugodacus cucurbitae*、茄二十八星瓢虫 *Henosepilachna vigintioctopunctata* | 瓢虫 *Coccinella transversalis*、*Cheilomenes sexmaculata* |

| 可可 | 可可荚螟 *Conopomorpha cramerella*、盲蝽 *Helopeltis theivora* | 黑蚂蚁 *Dolichoderus thoracicus* |

学名以制作时的现行名称为准，旧名列为异名。每项事实记录来源网址与核对日期于

### 第 6 阶段：野外观察与安全（参考台江图鉴 p.36–37，改为马来西亚情况）
穿着与工具、观察记录方法；要注意的昆虫（刺蛾幼虫、隐翅虫、蜂类）；被螫咬后的处理。

## 5. 辨识流程

- 依台江图鉴 p.38–40 二分检索表（附录 A），扩充马来西亚常见的目：
  竹节虫目、蜉蝣目、毛翅目、缨翅目，并加入"不在检索表内，请请教专家"的结果。
- 每题一个可见特征，配示意图与两个（少数三个）大按钮；"看不清楚"显示提示。
- 顶部显示已答路径，可点任一步返回修改。
- 结果页：类群、所属目、关键特征核对清单（逐项打勾）、容易混淆的类群、前往该目介绍。
- 注明：只适用于成虫与常见昆虫，精确鉴定请教专家。

## 6. 帮助记忆

1. 名字由来：每个目拆解希腊文（例：Lepido 鳞 + ptera 翅 = 鳞翅目）。
2. 对比表：蝴蝶/蛾/弄蝶、蜻蜓/豆娘、蝗虫/螽斯、蜜蜂/食蚜蝇、甲虫/蝽、蛾/石蛾、
   蜉蝣/石蝇、白蚁/蚂蚁。
3. 口诀：每目一句短句，三种语言各写，不硬翻。

## 8. 图片

- 解剖、触角、口器、足、翅、生活史、各目代表：自绘 SVG 示意图。
- 物种照片，按以下优先顺序：
  1. MPOB 照片：MPOB 已同意使用，条件为注明出处。目前采用 14 张，出自
     《Risalah Sawit》第 12、34、40 期（袋蛾三种与 *M. plana* 完整生活史、袋蛾危害、
     犀角金龟生活史、*Sycanus dichotomus* 标本、感染 OrNV 的犀角金龟幼虫）。
     标注格式："照片：马来西亚棕油局（MPOB），引自《Risalah Sawit》第 N 期（年份）"。
     小册中注明由第三方提供的照片（如 "Arnold H. Hara, 2014"、"gambar sumbangan
     En. Yap Tect Hean"）不使用。
  2. iNaturalist、Wikimedia Commons 上 CC0 / CC BY / CC BY-SA 的照片，标注拍摄者与授权。
  3. 用户自己拍的照片。
- 不使用任何未授权照片（包括台江图鉴、WTKhoo 汇编、一般网站）。
- 找不到合格照片的物种显示示意图或"暂无照片"，不用同属其他物种冒充。
  目前缺：刺蛾 *Setora nitens*、*Orthocraspeda trima*；白蚁 *C. curvignathus*；
  授粉象甲 *E. kamerunicus*（Commons 有少量候选待逐张检查）。
- 照片转 WebP，每张约 50–80 KB；"关于"页列出全部图片来源。
- MPOB 照片多为 300–450 像素宽的扫描或印刷图，只作页内图片，不提供全屏放大。

## 9. 品质检查

- 内容检查脚本：三种语言齐全、每个检索结果指向存在的页面、无死路与循环、
  每个物种都有所属目、每张照片都有来源与授权、每项马来西亚事实都有来源记录。
- 浏览器测试：首次语言选择、三条以上完整辨识路径、切换语言与主题、字体大小、
  划线与笔记、测验计分、离线重新载入。
- 分类核对：白蚁归蜚蠊目、衣鱼目为 Zygentoma、同翅目并入半翅目、弹尾虫非昆虫、
  鱼蛉属广翅目。
