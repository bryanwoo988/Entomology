# 昆虫 · Bugs · Serangga Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An offline, trilingual PWA that teaches insect anatomy, life cycles and orders, identifies an insect to order step by step, and covers Malaysia's common agricultural insects with sourced identification and control information, plus flashcards, quizzes and exams.

**Architecture:** A fork of the Meteorology app (`/home/user/bryanwoo988/meteorology`, read-only clone of `bryanwoo988/meteorology`): static files, hash router in `js/app.js`, content as per-page JSON in `data/` generated by Python scripts in `tools/content/`, shared `js/reader.js` for highlights/notes/bookmarks/read-aloud, a generated precache service worker. New pure modules add the identification key, dual Chinese names, pesticide registry, Leitner flashcards and exams; new block types render species headers, photos and control sections.

**Tech Stack:** HTML, CSS, ES modules (no framework, no npm dependencies, no CDN); Node 22 `node --test` for unit tests; `tests/index.html` + `tests/browser.js` for in-browser tests (Playwright/Chromium headless to run them); Python 3 + Pillow for content and image tooling; GitHub Actions + GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-21-insect-id-pwa-design.md`

## Global Constraints

- App names: `昆虫` (zh), `Bugs` (en), `Serangga` (ms). Title string `昆虫 · Bugs · Serangga`.
- Published URL: `https://bryanwoo988.github.io/Entomology/` (in `js/config.js` `APP_URL`, `index.html` og tags, `manifest.webmanifest`).
- Languages `['zh', 'en', 'ms']`; default `en`; first visit shows the language picker.
- Storage prefix `bugs.` (prefs key `bugs.prefs.v1`); service-worker cache prefix `bugs-`; the worker deletes only caches starting with `bugs-`.
- Themes exactly as Meteorology: `auto|light|dark`, light looks `classic, paper, mint, lavender`, dark looks `midnight, oled, slate, grape`; text scales `[1, 1.15, 1.3, 1.5]`.
- `woobrothers.my/APP-STANDARDS.md`: what's-new sheet after an update (not for new users), update offered not forced, Settings/About shows offline QR code, URL, share-link button, version · date, full update history.
- Every release adds an entry at the top of `data/releases.json` with `v`, `date` (YYYY-MM-DD) and notes in zh/en/ms; fixes bump the patch digit, features the minor digit.
- Every markable content block on every page carries `src` (spec §10.4). The linter fails a block without it.
- Chinese names: where mainland and Taiwan names differ, show `大陆名（大陆）／台湾名（台湾）` in zh; both are searchable.
- Control methods in IPM order: `monitor` → `cultural` (incl. mechanical/physical) → `biological` → `chemical`. Chemical blocks name active ingredients only; a dose appears only when quoted from a source with year. Every active ingredient is checked against Malaysia's Pesticides Board (Lembaga Racun Makhluk Perosak) before inclusion; banned ones are labelled 已禁用 / Banned / Diharamkan; unknown status may not ship. Every species page with a chemical section shows the label-reading warning.
- Photos: MPOB photos credited `照片：马来西亚棕油局（MPOB），引自《Risalah Sawit》第 N 期（YYYY）` / `Photo: Malaysian Palm Oil Board (MPOB), from Risalah Sawit No. N (YYYY)` / `Foto: Lembaga Minyak Sawit Malaysia (MPOB), daripada Risalah Sawit Bil. N (YYYY)`. Other photos only CC0, CC BY, CC BY-SA, with author and licence. No photo of another species stands in for a missing one.
- Taxonomy: termites under Blattodea (formerly Isoptera); Zygentoma (formerly Thysanura); Homoptera merged into Hemiptera; Collembola, Protura, Diplura are hexapods but not insects; fishflies in Megaloptera.
- No book text, Taijiang photos or WTKhoo photos are copied; reference books never enter the repo (`.gitignore` `References/`, `*.pdf`).
- Never put the user's email or personal data in requests to external services, including User-Agent strings.

## Review Focus

1. **A term with no Taiwan name** — zh shows the mainland name alone, with no `（大陆）` suffix and no empty `／（台湾）`. Test in Task 3.
2. **Changing an earlier answer in the key** — tapping step 2 of a 5-step path drops steps 3–5 and asks step 3 again; it never shows a stale result. Test in Task 5.
3. **Corrupted or old saved progress** (Leitner boxes, wrong-answer book, exam history from a hand-edited or older `bugs.prefs.v1`) — the app starts with clean defaults for the bad fields and keeps the good ones. Test in Task 7.
4. **A pesticide whose registration status is `unknown`, or a banned one shown without its label** — the linter fails the build. Test in Task 4.
5. **Precache growing past the budget once photos are added** — `tools/build-sw.mjs` prints the size and exits non-zero above 12 MB. Test in Task 1.

**Interfaces:**
- `data/key.json`: `{start:'n1', nodes:{ '<id>': {q:{zh,en,ms}, hint:{zh,en,ms}, img?:'img/svg/key-<id>.svg', options:[{label:{zh,en,ms}, img?, next?:'<id>', result?:'<result id>'}]} }, results:{ '<id>': {group:{zh,zhTw?,en,ms}, order:'pNN'|null, check:[{zh,en,ms}], confused:[{zh,en,ms}], src:[...] } } }`. - `js/key.js` (pure):
  - `walk(key, answers:number[]) -> {path:[{node, choice}], node?:string, result?:string}` — follows answers from `start`; stops at the first result.
  - `answerAt(answers, step, choice) -> number[]` — returns `answers.slice(0, step).concat(choice)`.
  - `encode(answers) -> string` / `decode(str) -> number[]` — answers as dot-joined digits for the URL (`#/key/0.1.1`); `decode` returns `[]` for anything not matching `/^\d(\.\d)*$/`.
  - `validate(key) -> string[]` — errors: unknown `next`/`result`, unreachable node, cycle, option with both or neither of `next`/`result`.
